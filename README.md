# User Management Web Application

## Project Overview
This project is a simple User Management Web Application developed using Python Flask, HTML, CSS, and SQLite.

## Features
- Add user details
- Store data in SQLite database
- Display all users in a table
- Clean and responsive UI

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
